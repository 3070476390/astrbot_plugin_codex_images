# AstrBot Codex 绘图

在 AstrBot 的“扩展功能 → Codex 绘图”中管理 Codex 订阅账号和 OpenAI API 绘图。机器人通过同一组聊天命令回传图片。Codex 模式可用统一账号或每人独立账号。

**版本 0.8.4 支持用 `/codex模型` 查看并按编号切换模型。** 两种绘图模式都支持文生图、单图编辑、出图比例、重绘和临时图库。真实账号和消息平台联调仍待完成。

## 运行条件

- AstrBot 4.29.4 或以上的 4.x 版本，Python 3.11+。已按 4.29.4 的 Plugin View、侧栏和 Web API 源码适配。
- Codex 模式需要在 AstrBot 所在机器或容器内安装支持 `chatgptDeviceCode` 和内置生图的官方 Codex CLI。账号需具备图像生成权限和可用订阅额度。
- API 模式需要有图像模型权限和可用额度的 OpenAI API 项目及其密钥。AstrBot 运行环境须能访问 `api.openai.com`。

本地验证所用 CLI 为 `0.166.0-alpha.5.1`：已验证真实协议初始化、空白账号状态及进程退出，已核对其生成的 JSON Schema。**没有把这次协议验证视为真实出图验证，也不保证其他 CLI 版本兼容。** app-server 接口和图片返回格式可能变化。

## 安装

在 AstrBot **插件 → 安装插件（＋）→ 从链接安装** 中填写 `https://github.com/3070476390/astrbot_plugin_codex_images`。也可以从 GitHub Releases 下载 ZIP，再在 AstrBot 中从文件安装。

- [下载 v0.8.4 安装包](https://github.com/3070476390/astrbot_plugin_codex_images/releases/download/v0.8.4/astrbot_plugin_codex_images-v0.8.4.zip)
- [查看所有版本和安装包](https://github.com/3070476390/astrbot_plugin_codex_images/releases)

1. 将安装包上传到 AstrBot 插件管理的本地安装入口。从当前源码运行 `python scripts/build_zip.py` 可在 `dist/` 生成 v0.8.4 安装包。手动放置源码时，目录为 `data/plugins/astrbot_plugin_codex_images/`，`main.py`、`metadata.yaml` 和 `views/` 应位于该目录顶层。
2. 插件使用 Pillow 和 HTTPX，AstrBot 4.29.4 已包含这些依赖。
3. 使用 Codex 订阅时，在插件配置中填写 `codex_command`，Linux 通常为 `codex` 或其绝对路径。Windows 使用原生 `codex.exe` 的完整路径。
4. 重载插件并刷新 AstrBot 后台，左侧“扩展功能”中会出现 **Codex 绘图**。也可通过插件详情页打开 `dashboard` 视图。
5. 填写使用名单或开启“允许所有用户使用”。统一账号可通过“登录 Codex 订阅账号”获取设备码并完成登录。使用 API 模式时，按下面的配置步骤启用。
6. 允许的聊天用户发送 `/codex画图 图片描述` 即可绘图。

升级 0.1.0：新版本默认使用统一账号模式，需要在扩展页面单独登录，**不会自动把任何原有用户凭据复制为统一账号**。切换到“每人独立账号”可继续使用原有个人登录记录。未开启“允许所有用户使用”时，空使用名单在统一模式中仅允许 AstrBot 聊天管理员。

如果使用官方 npm 包，在 Linux 上可通过 `npm install -g @openai/codex` 安装 CLI。以官方 [CLI 文档](https://learn.chatgpt.com/docs/cli) 为准。Windows 可使用已有桌面应用附带的 CLI 或官方原生二进制；升级后绝对路径可能变化，需要同步更新配置。

## 使用

```text
/codex模式
/codex模式 1
/codex模式 2
/codex登录
/codex状态
/codex画图 一只撑着透明雨伞的橘猫，水彩插画，柔和的蓝绿色背景
/codex画图 --比例 9:16 雨夜街景，手机壁纸
/codex改图 保留人物，把背景改成雪山
/codex重绘
/codex模型
/codex模型 页 2
/codex模型 12
/codex模型 默认
/codex额度
/codex取消
/codex退出
```

统一模式由管理员在扩展页面完成登录和退出。聊天端可使用绘图、改图、重绘、模型、额度、状态和取消命令。用户只能取消自己发起的任务。统一账号同时运行一个任务，繁忙时提示稍后重试。

独立模式：用户私聊发送 `/codex登录` 后获取官方 `auth.openai.com` 页面和设备码，并在自己的浏览器登录。每个平台实例、每个用户仍有独立账号目录。两种模式的凭据均由 Codex 保存在 **机器人服务器** 上，不需要向机器人发送密码、令牌或 `auth.json`。

默认仅允许私聊。开启 `allow_group_images` 后，允许的群成员可按当前账号模式绘图，图片会回传到发起请求的群。聊天端账号操作仍仅限私聊。

每次输出一张图片，支持文生图和单张参考图编辑。没有实现多图融合、批量生成、蒙版局部编辑或跨平台账号绑定。

### OpenAI API 模式

1. 在 **插件 → Codex 绘图 → 配置**，或 **扩展功能 → Codex 绘图 → 绘图设置 → OpenAI API 绘图** 填写 OpenAI API Key。此前通过环境变量配置的部署，升级后需要在这里重新填写密钥。
2. 打开 **扩展功能 → Codex 绘图 → 绘图设置 → OpenAI API 绘图**。保存密钥后，图片模型下拉列表会显示该 API 项目可见的 GPT Image 模型，也可手动刷新。选择模型，启用 **允许切换到 API 模式**，再保存。默认模型为 `gpt-image-2.6-flare`，默认质量为中。
3. 有绘图权限的用户发送 `/codex模式` 可查看模式列表，当前模式带有 ✓。用 `/codex模式 1` 切换到 Codex 订阅，用 `/codex模式 2` 切换到 OpenAI API，原有的 `Codex` 和 `API` 参数也可继续使用。插件按平台实例和用户保存选择，首次使用默认为 Codex。

扩展页面只显示密钥的配置状态。留空后保存会保留现有密钥，填写新值会更换，勾选 **清除已保存的密钥** 后保存会移除。使用 AstrBot 原生插件配置时，可以清空密钥字段后保存。密钥由 AstrBot 保存到服务器的插件配置文件中，密码字段的掩码不加密文件内容。

读取列表使用 OpenAI 的模型目录接口。插件按模型 ID 筛选兼容的图像模型，并跳过已停用的型号。查询目录无需发起出图请求，出图权限以实际调用结果为准。当前配置未出现在返回列表中时会保留，管理员可选择其他模型后保存。

API 模式直接调用 OpenAI Images API，文生图使用 `/v1/images/generations`，图生图使用 `/v1/images/edits`。用量计入管理员的 API 项目，由管理员在 [OpenAI API 用量页](https://platform.openai.com/usage) 查看。已有名单、所有用户开关和群聊开关都适用于 API 绘图。关闭 API 开关后，已选择 API 的用户可手动切回 Codex。插件每次只发送一次收费请求，同时处理一个 API 绘图任务。任务取消或超时后，已提交给服务端的请求仍可能计费。

### 临时图库

打开 **扩展功能 → Codex 绘图 → 图库**。AstrBot 后台管理员可以按模式和关键词筛选，点击图片查看较大预览、生成时间、提示词和尺寸，也可以下载原图。

- 默认收录更新后新生成的结果，包括私聊和群聊出图。图库保留原图、缩略图、提示词和生成参数中用于展示的模型及模式。关闭 **绘图设置 → 将新出图存入临时图库** 后，已有图片仍可查看至到期。
- 图片最多保留 7 天，插件运行时定期清理到期数据。图库最多保存 120 张，原图和缩略图合计上限 256 MiB，达到上限时先清理最早生成的图片。
- 图库存储在 AstrBot 插件数据目录的 `gallery/images.sqlite3`，从升级后的第一张新图开始积累。重启后仍可查看有效记录。

### 允许所有用户使用

在 **扩展功能 → Codex 绘图 → 绘图设置 → 账号与访问** 中打开 **允许所有用户使用**，点击 **保存设置**，即可让所有能向机器人发送指令的用户使用插件，无需逐个填写 ID。也可在原生插件配置中将 `allow_all_users` 设为 `true`，再按该面板提示重载插件。

统一模式下所有调用共用管理员登录的账号和额度，独立模式下仍使用每个人自己的账号。已有使用名单会保留；关闭此开关后，名单规则恢复。新开关默认关闭，升级不会自动改变原来的访问范围。

若希望在群里使用，还需打开 **允许群聊绘图**。AstrBot 自身的访问控制仍需允许这些消息进入插件。所有用户模式也不授予后台管理权限；用户仍只能取消自己发起的绘图任务。

### 图生图

将 **一张图片和 `/codex改图 修改要求` 放在同一条消息中发送**，例如附上照片并发送 `/codex改图 改成水彩插画，保留主体构图`。也可以引用一条带图片的消息后发送该指令，前提是消息平台会在引用消息链中提供图片；没有读到引用图片时，请改为同条消息附图。

`/codex图生图` 是 `/codex改图` 的别名。`/codex画图` 在消息附图或引用图片时也会自动进入图生图；不附图时继续文生图。同条消息中的图片优先于引用图片，不读取跨消息缓存或其他用户的最近图片。

一次支持一张参考图，格式为 PNG、JPEG 或 WebP，大小不能超过配置中的 `max_image_mb`。GIF 等格式请先转换。参考图通过 AstrBot 的媒体解析器读取，复制到当前账号任务的临时目录，以 Codex `localImage` 输入传递；任务结束、失败或取消后清理插件创建的参考图副本，AstrBot 自身的媒体缓存由其管理。读取参考图计入本次绘图超时，支持中途取消。

### 出图比例与重绘

- 在 `/codex画图` 或 `/codex改图` 的描述前加 `--比例 1:1`、`--比例 9:16` 或 `--比例 16:9`。插件请 Codex 按指定比例构图，返回尺寸不符时居中裁切到精确比例。省略该参数时，按 Codex 返回的尺寸发送。
- 引用自己的出图结果发送 `/codex重绘`。如果平台将文字和图片分开发送，引用编号文字，或直接发送图片旁显示的 `/codex重绘 编号`。重绘复用原提示词、比例、模型、参考图及 API 出图质量。重绘时需处于原出图模式，用量计入该模式。
- 重绘记录只存于插件内存，限原发起人在同一会话使用。记录会在最近一次成功出图后保留最多 30 分钟。缓存达到 128 条或参考图共 64 MiB 时会淘汰较旧记录，插件重启后需重新发起绘图。

### 查看和切换模型

发送 `/codex模型` 或 `/codex模型列表` 查看当前绘图模式下的模型。列表每页显示 10 个模型，编号跨页连续，当前模型末尾带 ✓。用 `/codex模型 页 2` 查看第二页，在同一会话中发送 `/codex模型 12` 切换到编号 12 的模型。用 `/codex模型 默认` 恢复使用后台默认模型。

选择按用户和绘图模式保存。Codex 统一账号和独立账号各自保存选择。切换影响该用户之后发起的绘图，重绘继续使用原任务的模型。

Codex 模式通过 `model/list` 获取已登录账号可见的调度模型，并标注默认模型与图片输入能力。OpenAI API 模式使用已保存的密钥查询项目可见的图像模型。出图权限以实际调用结果为准。

### 账号额度

API 模式下，`/codex额度` 提供项目用量查询入口。

发送 `/codex额度`（别名 `/codex用量`）查询当前绘图账号通过官方 `account/rateLimits/read` 返回的额度。统一模式中，允许的聊天用户和聊天管理员可查询统一账号；独立模式查询自己的账号。群聊查询沿用“允许群聊绘图”开关。

管理员也可进入 **扩展功能 → Codex 绘图 → 账号额度**，确认统一账号已登录后点击 **刷新额度**。面板显示上次查询时间和快照；后台状态轮询不会反复请求 Codex 额度。有任务运行时请等待完成再刷新。退出登录、重新登录或保存设置会清除旧快照；查询失败会显示错误，不沿用旧百分比。

- 按服务返回的额度分组展示已用/剩余百分比、窗口时长和下次重置时间。支持单分组及多分组协议，不固定假设一定存在 5 小时或周额度。
- 如服务提供，则展示订阅类型、Credits 余额、已达到的限制和可用额度重置次数。仅查询与展示，不消费重置次数、不发起充值或模型推理。
- 没有返回的数据标为“未提供”；没有额度数据不代表剩余为零，重置时间已到也不自动认定额度恢复。Credits 不限额也不代表其他用量窗口不限额。
- 聊天中的时间标为 UTC+8，网页按浏览器本地时间显示。聊天最多展示前 6 个额度分组，面板最多展示前 20 个。
- **这是 Codex 账号额度，不能换算为还能生成多少张图片。** 具体能否出图以真实调用为准。旧 CLI 不支持该接口时会提示升级，未登录、网络错误和任务繁忙也会明确提示。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `account_mode` | `shared` | `shared` 为统一账号，`personal` 为每人独立账号 |
| `codex_command` | `codex` | 可执行文件名称或完整路径，不接受命令行参数 |
| `model` | 空 | 使用 Codex 默认调度模型；可填写账号可用的 Codex 模型，不能填图像模型名 |
| `openai_api_enabled` | `false` | 允许有绘图权限的用户切换到 OpenAI API 模式 |
| `openai_api_key` | 空 | 用于 API 模式的 OpenAI 项目密钥，在插件配置界面设置 |
| `openai_image_model` | `gpt-image-2.6-flare` | 管理员指定的 OpenAI 图像模型 ID |
| `openai_image_quality` | `medium` | API 出图质量，可选 `low`、`medium`、`high` |
| `gallery_enabled` | `true` | 自动收录新出图和提示词到管理员临时图库 |
| `allow_group_images` | `false` | 是否允许群聊绘图 |
| `allow_all_users` | `false` | 开启后所有聊天用户可使用，忽略使用名单；群聊仍需单独开启。关闭后恢复原有名单规则 |
| `allowed_users` | `[]` | 所有用户开关关闭时生效。填写 `平台实例ID:用户ID`，用 `/sid` 的 Bot ID 和 UID 拼接。统一模式始终允许聊天管理员，空名单仅管理员；独立模式空名单允许所有用户使用自己的账号 |
| `max_sessions` | `4` | 1–32；登录等待、状态查询和绘图均计入。每个账号同时一个任务，因此统一账号同时只绘制一张图 |
| `request_timeout` | `30` | 单次协议请求超时，5–120 秒 |
| `login_timeout` | `900` | 等待用户完成登录，30–1800 秒；设备码可能更早失效 |
| `generation_timeout` | `300` | 单次绘图等待上限，30–1800 秒 |
| `max_image_mb` | `20` | 输入参考图和输出图片的大小上限，1–30 MB |
| `max_prompt_chars` | `4000` | 描述长度上限，1–16000 字符 |

扩展页面会校验字段；保存后对新任务生效，无需重载。有任务运行时禁止保存。通过 AstrBot 原生插件配置面板修改时，按该面板提示重载插件。错误配置可能导致插件加载失败。

## 数据和运行方式

数据位于 AstrBot 的 `data/plugin_data/astrbot_plugin_codex_images/`：

```text
users/<账号标识的 SHA-256>/
  codex/                 # 独立 CODEX_HOME；Codex 管理凭据和刷新
  jobs/<随机任务标识>/     # 绘图工作目录和临时回传图片
```

- Codex 登录凭据采用专用目录中的文件存储。Codex 子进程与 OpenAI API 模式的插件配置密钥隔离。
- 统一账号使用专用账号标识，与独立用户目录分开。统一账号管理仅允许 AstrBot 配置中的后台管理员；普通 API Key 和其他用户名不能访问。所有请求通过 AstrBot 的受限 iframe bridge，页面不获取后台令牌。
- 统一模式的设备码仅显示于管理页面，独立模式通过私聊发送。页面刷新后可继续等待正在进行的登录；成功、失败、超时或取消后移除设备码。状态不展示邮箱、令牌或账号详细信息。日志不写入上游响应和 stderr。
- 每个任务启动独立 app-server，任务结束、超时、取消或插件停止时回收。取消可能无法撤回已发生的服务端用量。
- 模型会话使用只读沙箱，禁用 shell、浏览器、电脑控制、插件、MCP 应用及子代理；客户端拒绝服务端权限申请和自定义工具请求。
- 账号目录隔离是应用层隔离，**不是独立的系统用户或容器安全边界**。建议在专用容器/系统账号下部署；不要把服务器上的敏感工作目录挂载给它。管理员可按需要选择使用名单或允许所有用户。
- 只从 `imageGeneration` 完成事件提取图片，支持 Base64 和本用户工作目录或 `codex/generated_images` 下的 `savedPath`。不从模型自然语言中提取文件路径，不下载任意图片 URL。
- 回传副本在发送结束后删除；Codex 自己生成的原图、缓存和诊断文件可能保留，需由管理员按实际磁盘占用维护。退出登录不承诺清空所有历史缓存，卸载插件也不主动递归删除数据目录。
- 多进程 AstrBot 实例不应共享同一个插件数据目录；本版并发控制在单进程内生效。

## 验证和排障

```bash
python -m unittest discover -s tests -v
python scripts/smoke_codex.py --codex /path/to/codex
python scripts/build_zip.py
```

单元测试使用本地模拟 app-server，通过真实子进程和 JSONL 管道验证登录、通知先于响应、重复事件、用户隔离、取消、超时、异常退出、图片路径检查、图生图参考图传递与清理，以及模型分页查询。`smoke_codex.py` 使用临时空白账号目录验证真实 CLI 协议，不登录、不调用模型、不生成图片。

界面测试：安装 Playwright 并确保 Edge 可用后执行 `node tests/view_smoke.cjs`，使用本地模拟 bridge 验证登录轮询、设备码清理、名单与配置保存、保存失败、草稿保留、退出、主题和手机布局。测试预览输出到 `dist/dashboard-preview.png` 等文件；截图中的登录状态是模拟数据。

真实部署验收：扩展页面登录 → 显示已连接 → 设置名单并保存 → 查询模型 → 文生图 → 附图/引用图改图 → 名单外用户被拒绝 → 用户不能取消别人的任务 → 页面退出后无法继续绘图。独立模式另验不同用户账号隔离。

常见问题：

- **找不到 Codex / 无法启动**：检查路径、容器内安装情况、可执行权限。Windows 的异步子进程需要可用的 Proactor 事件循环；某些执行沙箱会阻止创建子进程管道。
- **扩展菜单没有入口**：确认安装包包含 `views/dashboard/index.html`，AstrBot 版本至少为 4.29.4，插件已启用；重载插件并刷新整个后台。
- **设备码页面无法直接打开新窗口**：AstrBot 视图 iframe 限制弹窗，请复制官方地址到浏览器新标签页。复制按钮不受支持时，可选中文本后按 Ctrl+C / ⌘C。
- **登录接口失败**：检查 CLI 是否支持设备码流程、账号是否允许设备码登录，以及网络代理。不会改用群聊收集凭据。
- **登录成功但无图片**：不代表图像权限可用。确认账号与 CLI 支持内置生图，并检查订阅额度和模型设置。
- **仅返回图片引用**：本版不猜测私有文件下载接口；只支持带 Base64 或受限本地路径的结果。需要使用兼容 CLI 或适配其公开的新协议。
- **只收到内部错误**：日志只含异常类型；可先用隔离环境运行上述协议检查。向他人提供排障材料前，请移除设备码和凭据。
